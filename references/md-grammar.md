# 分镜稿 md 语法（engine: case-ingest.mjs）

一期视频 = 一个 `content/<slug>.md`。语法极简：`## 卡型` 开头定一镜，下面 `字段: 值` 填内容。
同一字段写多行 → 自动收集成数组（如多个 point/row）。`#` 开头是注释会被忽略。

## 卡型清单（每 `## xxx` = 一屏/一镜）

### meta（全局，不是镜头）
```
## meta
title: 视频标题
theme: counseling | energy | warm   ← 题材调色，整片生效
voice: Brian                    ← 音色名（可省）
```

### head —— 片头引子 / 频道片头
字段：`subtitle`(小标) / `caption`(口播)。
用于开场悬念句、自我介绍。可多张连续（每张一句），别超过 2 张。

### points —— 要点卡（痛点/方案/启示通用）
字段：`kicker`(左上小标签) / `point`(要点，可多条) / `caption`。
每条 point 尽量 ≤ 30 字，≥1 行就拆成两条。

### data —— 大数字卡（单个冲击数字）
字段：`kicker` / `value`(大数字) / `label`(数字的说明) / `caption`。
`value` 建议带正负号/单位（如 -91.8%、2-3年、数亿元），字号很大，别塞长句。

**`value` 长度铁律（来自 EP001 实测）**：`value` 越短字号越大、冲击力越强。若
- 数字或短短语（≤4 字）→ 用 `data` 卡（最佳，例如 `-91.8%`、`千亿级`、`35秒`）
- 长句子（≥6 字短语或完整一句话，例如 "先学规矩，再学优化"）→ 改用 `points` 或 `head` 卡，长 value 在 `data` 卡上会填满画面、看起来信息密度过墙

### stats —— 多组数字卡（4 组内）
字段：`kicker` / `row`(每组一行：`数字 说明`，空格分隔，可多条) / `caption`。
如 `row: 2000座 接入变电站`。

### theory —— 认知拆解卡（科普/心理向核心卡）
字段：`kicker`(理论名) / `headline`(居中大概念/公式，如 `7-38-55`) / `row` 或 `point`(每组一行：`比例 说明`) / `caption`。
适用：把一条规律/比例拆开给观众（梅拉宾法则 7-38-55、注意力曲线等）。心理疏导/知识科普高频用。

### out —— 片尾卡
字段：`slogan`(金句大标题) / `tagline`(关注引导按钮文案) / `caption`。

## 字段通用规则
- `caption` = 本镜口播本体（TTS 读它 + 卡拉OK字幕显示它）。**一句话 ≤ 40 字（约 2 行）**；超长就把这句拆成连续两镜（kicker 可相同）。
- 每镜都要有 `caption` 吗？建议有（静音卡会让观众感觉断层）。信息型卡（data/stats）尤其要配 caption 讲给观众听。
- `broll:` 关键词 → 该镜背景播放竖屏视频素材 + 自动静音。纯信息卡连排会单调，尽量隔镜给关键词。同镜别复用已用画面。
- 单镜 point/row 上限 4 条；再多就拆镜，避免内容溢出。

## 示例片段（counseling 心理疏导 · 认知卡）
```
## meta
title: 第一眼就定生死了吗？
theme: counseling
voice: Brian

## head
subtitle: 心理疏导 · 每周拆一个真相
caption: 你以为沟通靠的是能说会道？其实对方早就在观察你了。

## theory
kicker: 梅拉宾法则
headline: 7-38-55
row: 7% 你说了什么
row: 38% 你的语气
row: 55% 你的表情和肢体
caption: 心理学有个梅拉宾法则，说话内容只占百分之七，剩下九十三靠语气和身体。

## out
slogan: 晚遇知缘
tagline: 关注我 · 看透人际关系底层逻辑
caption: 所以别只顾准备话术，把状态调到最好，比什么都管用。
```
