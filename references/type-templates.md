# 视频类型模板（type-templates）

供 publisher Skill 把口播稿映射成分镜稿。**选题、叙事、钩子怎么写不在本 Skill 职责**——那由"口播稿生成 Skill"产出。这里只提供"这种类型的视频通常长什么样"的**结构参考** + 该题材的 palette/B-roll 基调，帮助把一段已写好的稿**忠实落成分镜**。

若调用方给的口播稿已自带清晰分段（钩子/展开/数据/结尾），**逐段直译即可，不要为了"结构好看"改写它的语义**。以下骨架仅在口播稿是"一整段无分节文字"时，才作为拆分顺序参考。

---

## type: counseling（心理疏导 / 情感口播 / 软科普）
- **palette**：暖 Soft Signal（浅暖底 + 珊瑚橙 accent）。视觉亲切、共情向。
- **B-roll 基调**：安静交谈、单人思考、柔和灯光、城市暖光、肢体语言特写、日落等生活暖调。
- **常用卡序列（整段无分节稿时的兜底拆分参考）**
  1. `head` 一句反常识/悬念引子（别占多张）
  2. `theory`/`points` 认知拆解（心理学概念 / 规律 / 数字比例）
  3. `points` 双视角或真相点
  4. `data` 关键数据冲击（如有）
  5. `out` slogan + 关注引导
- **典型 caption 语气**：口语化、带节奏的解说，短句为主。

## type: energy（能源 / 企业数智化转型案例速览）
- **palette**：科技蓝深底 + 电光青 accent。视觉冷静、专业、数据感。
- **B-roll 基调**：电厂远景、控制室屏幕、数据中心、AI/预警类画面（用英文关键词）。
- **常用卡序列**
  1. `head` ×1-2 频道片头/引子
  2. `points` 行业痛点 / 背景（传统手段难突破）
  3. `points`/`data` 方案登场（发布什么、做了什么）
  4. `stats` 智能体分工 / 多维成效
  5. `data` ×1-2 冲击数字（如 -91.8%、投资回收期）
  6. `points` 行业启示 / 方法论
  7. `out` slogan + 关注引导

## type: warm（通用亲和向，未细分时兜底）
暖色备用。结构同 energy 的 points/data/out 主链，配色温和。

---

## 拆稿时的忠实度铁律（防"观感翻车"）
1. **caption 必须逐句对应原稿口播**——TTS 读什么，字幕就显示什么。不要把原稿信息偷塞进 point 而 caption 不讲（听众会割裂）。
2. 原稿某段讲数据 → 用 data/stats 卡承载数字 + caption 口播该数字。
3. 原稿讲概念/规律 → theory 卡（headline 放概念，row 放拆解）。
4. 原稿是连续叙述 → 按语义切成镜头，每镜一句 caption（≤40 字），切点=换气/换主题处。
5. **绝不为了"视觉好看"而新增原稿没有的观点或结论**。

## 每镜配图（broll 关键词）建议风格
- head/out：广角氛围（厂景/城景/日出日落）
- points(痛点)：人工巡检/控制室/低效场景
- theory：抽象概念/图表/人物互动
- data/stats：数据大屏/对比图表/行业实拍

素材源 Pexels，英文关键词命中率高。写关键词要具体可搜：`thermal power plant worker`、`two people coffee shop first date`。
